01
DATA ENGINEERING · WEB DATA · AI · ANALYTICS

F2B Price Intelligence Platform

Multi-platform product & pricing data pipeline with AI-driven product matching.
PROBLEM
Product information from different platforms uses inconsistent names, units, quantities and structures. Comparing them manually doesn't scale.
SOLUTION
Built an automated pipeline combining web data collection, product normalization, AI-assisted semantic matching and database storage — collecting data from Zepto, Blinkit, BigBasket and Farm2Bag, then mapping products into a standardized F2B structure for analytics.
KEY WORK
Multi-platform collection · product name standardization · semantic matching · quantity normalization · duplicate handling · historical price tracking · analytics dashboards.

DATA PLATFORM · MEDALLION ARCHITECTURE

DATUM — Modern Data Management Platform

A medallion-architecture data platform separating raw, processed and business-ready layers.
OVERVIEW
DATUM organizes data into structured Bronze, Silver and Gold layers to improve data quality, maintainability and downstream analytics.
LAYERS
Bronze — raw data with minimal transformation, preserving source. Silver — cleaning, deduplication, standardization, schema normalization, business rules. Gold — curated datasets for analytics, reporting and application consumption.
KEY WORK
Data ingestion · schema standardization · duplicate removal · quality rules · business-ready modeling · analytics integration.
MongoDBDatabricksPySpark PythonSQLPower BI
